Descomprime por completo el ZIP de Windows y ejecuta `janosos_game.exe` sin
separarlo de sus DLL y de la carpeta `data`.

El ZIP web debe servirse por HTTP; no se abre directamente desde `file://`:

```powershell
python -m http.server 8080 --directory C:\ruta\al\web
```

Después abre `http://127.0.0.1:8080/`.

Ambos paquetes usan el backend local predeterminado. Permiten completar la
campaña, ganar y gastar moneda, comprar/equipar progresión, desbloquear Boss
Rush y conservar los datos por cuenta en el dispositivo sin credenciales
cloud. Los resultados locales no se publican en el ranking global. El build de
producción se genera mediante el workflow de GitHub Pages con URL, publishable
key y callback de Supabase.
